# db

Database schema for Mukoo, managed with [Alembic](https://alembic.sqlalchemy.org/).
This directory is the **source of truth** for the schema — the app does not
create or alter tables at runtime.

## Usage

The connection URL comes from `DATABASE_URL` (falling back to the local-dev
value in `alembic.ini`). Run commands from this directory:

```bash
pip install -r requirements.txt

DATABASE_URL=postgresql+psycopg2://mukoo:mukoo@localhost:5432/mukoo alembic upgrade head
DATABASE_URL=… alembic downgrade -1
DATABASE_URL=… alembic history
DATABASE_URL=… alembic revision -m "describe change"
```

## Conventions

- Migrations are **authored by hand**, not autogenerated. GeoAlchemy2 spatial
  indexes do not round-trip cleanly through `--autogenerate`, so we keep DDL
  explicit and reviewable (`target_metadata = None` in `migrations/env.py`).
- The first migration enables the `postgis` extension.

## Migrations

- `0001_create_measurements_table` — PostGIS extension + `measurements` table,
  unique `sample_id`, GiST index on `geom`, index on `session_id`.
